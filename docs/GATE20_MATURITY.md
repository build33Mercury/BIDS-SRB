# Gate 20 software maturity checklist

## Implemented

- Installable Python package and versioned `bids-srb` CLI.
- Machine-readable JSON command output.
- Read-only dataset inspection and path-safety checks.
- Case-manifest schema plus fail-closed validation.
- Synthetic-only generation, mutation and repair.
- Hard-locked scientific `execute` command.
- Canonicalization with adversarial over-normalization tests.
- Comparison, reporting, static replay and provenance emission.
- Unit, negative, golden, property-like, path-safety and firewall tests.
- Commit-pinned GitHub Actions workflow.
- Clean wheel build and offline no-index install test.
- Platform, scope, failure-mode, security, semantic-version, changelog and tutorial documentation.
- Gate 2 systematic prior-art closure and narrowed public claim ceiling.
- Gate 15 canonicalizer v5.2 closure.
- Public `build33Mercury/BIDS-SRB` repository.
- Owner-approved MIT License.
- No hidden author-local path or credential required by the core package.

## Still required for Gate 20 closure

1. Successful public CI evidence for the exact final release commit.
2. Immutable public release tag bound to that audited commit.
3. Public release/archive provenance and a persistent archive identifier where required by the frozen gate rule.

A public source repository alone does not close Gate 20.
