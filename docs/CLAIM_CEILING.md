# Claim ceiling

BIDS-SRB is a research benchmark for controlled BIDS metadata semantic-robustness testing.

Permitted public framing is capability-specific. The project may describe its prospectively frozen combination of controlled semantics-preserving relations, semantics-changing metadata faults, layered response contracts, protected-payload checks, exact-version downstream observation, prespecified repair inverses, and preservation of silent/adverse/null outcomes.

Do not claim:
* first-ever BIDS metadata audit;
* no prior work;
* that metadata importance, metadata omissions, BIDS metadata curation, semantic metadata auditing, or OpenNeuro metadata gaps are themselves novel;
* prevalence, defect rates, comparative software reliability, or tool rankings from BIDS-SRB;
* independent human review.

Closest and adjacent prior-art families include CuBIDS, bids-utils, BABS, BIDS-Prov, Boutiques/BIDS application execution infrastructure, BIDS Validator/PyBIDS, and generic scientific-software metamorphic testing.
